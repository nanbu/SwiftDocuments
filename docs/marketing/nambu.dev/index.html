SwiftDocuments

Swiftで
Wordの文書を読む

Word の DOCX / DOCM を読み、文章・書式・表などを Swift の値型で扱うライブラリです。SwiftSheets と同じように、ファイル形式の違いを共通のモデルで扱うことを目指しています。

開発中・未リリースです。API は今後変更される可能性があります。

Wordの読み取りから

文書の構造を取り出す

段落、文字列と書式、表や結合セル、ハイパーリンク、画像への参照を取得できます。画像データは必要になった時に読み出します。

本文以外も確認する

ヘッダー・フッター、脚注・文末脚注、コメント、変更履歴を読み取ります。未対応の内容や参照の問題は警告で確認できます。

用途に合わせて読み込む

read は文書全体、inspect はパッケージ概要を読みます。scan は本文のブロックを順に処理し、処理済みの本文ブロックを保持しません。

scan でも入力ファイル、展開した本文 XML、関連する文書情報はメモリに保持します。メモリ使用量が一定になる方式ではありません。

短いコードで文章を取り出す

文書を読み込む

import Foundation
import SwiftDocuments

let url = URL(fileURLWithPath: "report.docx")
let result = try Document.read(contentsOf: url)
print(result.document.plainText)

for warning in result.warnings {
    print(warning.message)
}

本文をブロックごとに処理する

import Foundation
import SwiftDocuments

let url = URL(fileURLWithPath: "report.docx")
let result = try Document.scan(contentsOf: url) { block in
    print(block.plainText)
}
print(result.blocksRead)

上記はローカルの report.docx を読む例です。ブラウザ内で Swift は実行しません。

Swift Package Managerで導入

公開リポジトリの main ブランチを指定します。リリース版はまだ用意していません。

Package.swift の dependencies とターゲットの dependencies に追加してください。

// Package.swift
dependencies: [
    .package(
        url: "https://github.com/nanbu/SwiftDocuments.git",
        branch: "main"
    )
]

// Target dependencies
.product(name: "SwiftDocuments", package: "SwiftDocuments")

対応形式と開発の範囲

形式 状態 内容
DOCX / DOCM 読取実装あり Word の文書形式です。DOCM 内のマクロは実行しません。
ODT 設計・形式判定のみ LibreOffice Writer などが使う文書形式です。読み取り実装は今後追加する予定です。
Pages 設計・形式判定のみ Apple Pages の文書形式です。読み取り実装は今後追加する予定です。

現在は読み取りに取り組んでいます。文書の書き込み、形式変換、ページの描画やレイアウト、旧 Word の .doc、暗号化文書は未対応です。
