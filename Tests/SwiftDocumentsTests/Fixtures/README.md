# Fixture provenance

All content is synthetic. No customer documents are used.

- `minimal`, `stored`, `strict`, `relocated`, `features`, `unknown` and `macro` are specification-boundary packages built by `scripts/generate-fixtures.py`. The image in `features.docx` is a generated 1×1 PNG. The VBA part in `macro.docm` is an inert string, not executable VBA.
- `python-docx.docx` is independently generated by python-docx. `producer-oracle.json` contains paragraph and table expectations extracted by that library. Regenerate with `python3 scripts/generate-fixtures.py --producer` (requires python-docx). Test execution does not require Python.
- `libreoffice.docx` resaves the python-docx document with LibreOffice 26.2.3.2, Office Open XML Text filter. Default / even / first-page headers and footers become distinct parts; author metadata alone is normalized to synthetic values. Regenerate with `python3 scripts/resave-libreoffice.py --soffice /path/to/soffice`.
- `writer.odt` tests ODF MIME detection; `design.pages` / `spreadsheet.iwork` test IWA root types 10000 / 1. These are not complete application documents or evidence of ODT / Pages reading support.

Keep hand-built boundary fixtures and producer comparisons. Investigate changed producer parts before updating expectations.
